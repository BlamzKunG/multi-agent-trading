# Multi-Agent Trading Orchestrator

ระบบจัดการและรันออเดอร์ซื้อขายอัตโนมัติ ขับเคลื่อนด้วยสถาปัตยกรรมตัวแทนอัจฉริยะหลายตัว (Multi-Agent Architecture) ประมวลผลร่วมกับโมเดลภาษาขนาดใหญ่ (LLMs) รองรับการรันผ่านระบบพอร์ตจำลอง (Simulation Mode) และบัญชีจริงผ่านแพลตฟอร์ม MetaTrader 5 (MT5 Live Mode) โดยมีระบบวิเคราะห์แบ่งแยกตามสภาวะตลาดและกลยุทธ์การลงทุนที่หลากหลาย

---

## ส่วนประกอบของระบบ (System Architecture)

ระบบประกอบด้วยไฟล์หลักเพื่อทำงานแยกจากกันดังนี้:

1. **bot_orchestrator.py**: ตัวควบคุมวงจรรอบการทำงานหลักในโหมดจำลอง (Simulation Mode)
2. **bot_orchestrator_mt5.py**: ตัวควบคุมวงจรรอบการทำงานหลักที่เชื่อมต่อ MetaTrader 5 (MT5 Live Mode)
3. **gui_dashboard.py**: ส่วนติดต่อผู้ใช้งานบนเดสก์ท็อป (Desktop Dashboard GUI) พัฒนาด้วย Tkinter สำหรับตั้งค่าระบบ สลับโหมดการทำงาน ตั้งค่ากลยุทธ์รายตัว และแสดงประวัติการเทรดพร้อมสถิติเชิงลึก
4. **trading_agents.py**: คลาสหลักที่รวมระบบส่งสัญญาณของ AI Agents ทั้งระบบวิเคราะห์สภาวะตลาดหลัก (Market Regime) ทีมสไนเปอร์วิเคราะห์เทคนิครายกลยุทธ์ และด่านตรวจทานคำสั่งก่อนส่งโบรกเกอร์ (Reviewer Agent)
5. **performance_tracker.py**: โมดูลวิเคราะห์และคำนวณประสิทธิภาพการเทรดรายกลยุทธ์ด้วยตัวเลขสถิติขั้นสูง
6. **mt5_integration.py**: โมดูลสำหรับเชื่อมต่อ ส่งคำสั่ง เปิด-ปิด และตรวจสอบออเดอร์กับ MetaTrader 5 Terminal
7. **exchange_sim.py**: ระบบจำลองสภาวะพอร์ตและระบบคำนวณ Margin/PnL สำหรับการทดสอบออฟไลน์
8. **data_feed.py**: ตัวดึงข้อมูลราคาสินทรัพย์จริงผ่าน API สาธารณะ (Yahoo Finance)

## คุณสมบัติหลัก (Core Features)

### 1. ระบบจำแนกสภาวะตลาดส่วนกลาง (Market Regime Agent)
วิเคราะห์พฤติกรรมความผันผวนและระดับความแรงของแนวโน้มในปัจจุบัน เพื่อจัดกลุ่มทิศทางตลาดออกเป็นสภาวะย่อย เช่น Trend Strong, Trend Weak, Sideway, High Volatility, Low Volatility หรือ News เพื่อส่งต่อเป็นบริบทข้อมูลให้นักวิเคราะห์กลยุทธ์ตัดสินใจได้อย่างเหมาะสม

### 2. สามระบบกลยุทธ์เทรดแยกอิสระ
แต่ละกลยุทธ์ใช้ข้อมูล กรอบเวลาของแท่งเทียน คอนฟิก และผู้ช่วยวิเคราะห์ (Sub-agents) แตกต่างกันไปตามความเหมาะสม:
- **Scalping Agent**: เทรดตามแนวโน้มระยะสั้นและ Price Action บนกรอบเวลา M1/M5/M15/M30 ทำรอบเก็บสั้นและพักวิเคราะห์เร็ว
- **Day Trading Agent**: เล่นจบภายในวัน ไม่ถือครองออเดอร์ข้ามคืนอิงกรอบเวลา M15/H1/H4 คำนวณกรอบสวิงรายวัน (VWAP/Opening Range) และขยับ SL ป้องกันทุน
- **Swing Trading Agent**: เล่นกินคำใหญ่ระยะยาวระดับหลายวันถึงสัปดาห์อิงกรอบเวลา H4/D1/W1 วิเคราะห์แนวรับต้านยุทธศาสตร์และประเมินค่าธรรมเนียมถือคำสั่งข้ามคืน (Swap/Carry Cost)

### 3. ระบบความปลอดภัยตรวจสอบออเดอร์ (Reviewer Agent)
คอยดักจับทุกคำสั่งเปิดออเดอร์ (BUY/SELL) ของนักวิเคราะห์เป็นด่านสุดท้าย หากประเมินแล้วพบว่าสัญญาณเทรดนั้นขัดแย้งกับสภาวะตลาดหลัก หรือขนาดความเสี่ยงไม่เหมาะสม ระบบจะสั่งปรับคำสั่งเป็น HOLD เพื่อลดโอกาสขาดทุนโดยไม่จำเป็น

### 4. การจัดการความเสี่ยงและ Magic Number แยกขาดจากกัน
- **Magic Number Isolation**: คำสั่งเทรดของแต่ละกลยุทธ์จะถูกทำเครื่องหมายด้วย Magic Number เฉพาะตัว (Scalping = 111111, Day Trading = 222222, Swing = 333333) บอทจะเช็คสถานะและแก้ไขเฉพาะออเดอร์ของตนเองเท่านั้น ไม่รบกวนออเดอร์ของระบบอื่นหรือออเดอร์จากผู้ใช้
- **ATR Trailing Stop**: บอทจะใช้การขยับเลื่อน Stop Loss (SL) ตามความผันผวนของ ATR ผ่านโค้ดโปรแกรมในเครื่องโดยไม่ต้องพึ่งพา AI (0 Token) ตราบใดที่มีสถานะคำสั่งค้างอยู่ในพอร์ต

### 5. ระบบคิวเรียงลำดับการทำงาน (Sequential Queue Manager)
ระบบรันงานเบื้องหลังด้วยการต่อคิวคำสั่งประมวลผลกลยุทธ์ หากวงจรรอบเวลาการทำงานของแต่ละระบบเกิดชนกัน ตัวรันระบบจะทำการประมวลผลคำสั่งทีละคิวตามลำดับ ไม่เริ่มทำงานทับซ้อน เพื่อป้องกันปัญหาการรับส่งคำสั่งพร้อมกันในระดับ MT5 และลดความผิดพลาดของการจำกัดสิทธิ์ API

### 6. การทบทวนตัวเองเชิงลึก (Self-Reflection)
ก่อนเริ่มต้นวิเคราะห์ตลาดในรอบถัดไป บอทจะอ่านประวัติผลงานสถิติที่ผ่านมา (Win Rate, Profit Factor, Expectancy, Drawdown) และประวัติ 5 ออเดอร์ที่ถูกปิดล่าสุดของตัวเองมาเป็นบริบทในการเรียนรู้ เพื่อวิเคราะห์จุดบกพร่องและหลีกเลี่ยงการเปิดออเดอร์ซ้ำในแนวราคาสุ่มเสี่ยงเดิม

## การเตรียมการติดตั้ง (Installation)

### 1. ดาวน์โหลดซอร์สโค้ดของระบบ
```bash
git clone https://github.com/BlamzKunG/multi-agent-trading.git
cd multi-agent-trading
```

### 2. ติดตั้งไลบรารีที่เกี่ยวข้อง
```bash
pip install pandas requests numpy
```

สำหรับการเชื่อมต่อและสั่งการบัญชีเทรดจริงของ MetaTrader 5 (รองรับเฉพาะระบบปฏิบัติการ Windows เท่านั้น):
```bash
pip install MetaTrader5
```

## การกำหนดค่าและการใช้งาน (Configuration and Usage)

### 1. การตั้งค่า MaxPlus API Key
กรุณากำหนดค่าคีย์ MaxPlus API ใน Environment Variables ของระบบก่อนเริ่มต้นใช้งาน:

- **Windows (Command Prompt):**
  ```cmd
  set MAXPLUS_API_KEY="คีย์เข้าใช้งานของคุณ"
  ```
- **macOS / Linux:**
  ```bash
  export MAXPLUS_API_KEY="คีย์เข้าใช้งานของคุณ"
  ```

### 2. การเปิดใช้งานระบบผ่านเดสก์ท็อป (Desktop GUI Terminal)
คุณสามารถรันโปรแกรมหน้าต่างควบคุม Tkinter เพื่อตั้งค่าบัญชี กำหนดค่าพารามิเตอร์ของแต่ละกลยุทธ์ และเฝ้าดูประวัติการรันได้ผ่าน:
```bash
python gui_dashboard.py
```

ฟังก์ชันการทำงานหลักบน GUI:
- แท็บ **Global Setup**: ใช้สำหรับเลือกโหมดการทำงาน (Simulation / MT5 Live), กรอกข้อมูลล็อกอินบัญชี MT5 และกำหนดการเลือกใช้ AI Model
- แท็บกลยุทธ์รายตัว (**Scalping, Day Trading, Swing**): ปรับแต่งสวิตช์เปิดใช้งาน, เลข Magic, ขนาดสัญญาเทรดสูงสุด, รอบความเร็วกิจกรรม และพารามิเตอร์ปรับระยะ ATR Trailing Stop
- แท็บรายงานด้านขวา: แสดงยอดเงินบาลานซ์และอีควิตี้สะสม, รายชื่อคำสั่งที่ค้างอยู่แยกตามระบบ Agent, ประวัติออเดอร์ที่ถูกปิดแล้ว และหน้าตารางสรุปเปรียบเทียบสถิติเชิงลึก

### 3. การใช้งานคำสั่งประเมินแบบด่วน (Manual Trigger)
หากต้องการประมวลผลวิเคราะห์หาโอกาสในการยิงออเดอร์สำหรับกลยุทธ์ใดๆ ในทันที สามารถกดปุ่ม **Run Scalping**, **Run DayTrade** หรือ **Run Swing** บนหน้าเดสก์ท็อป GUI ระบบจะนำคำสั่งนั้นไปต่อคิวและเริ่มประมวลผลทันที
